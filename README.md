# Forge Agents LLC

Operational AI for offices that run on documented procedures — dental practices, medical and veterinary offices, law firms, property managers.

**The rule the whole company is built on:** an answer comes from the customer's own approved documents, with the citation verified verbatim against the source — or the assistant says plainly that it isn't documented and routes to the right person. It never invents an answer. The parts that make it refuse are tested harder than the parts that make it answer.

### OKA Anywhere

A remote MCP connector that puts an office's approved procedures inside Claude, ChatGPT, or any MCP-capable client.

- **Connector:** `https://console.forgeagentsai.com/mcp` · OAuth 2.1 (dynamic registration, PKCE, rotating refresh tokens)
- **Four tools:** grounded answers with verified quotes · verbatim claim verification · procedure search · an explicit list of what the documentation *doesn't* cover
- **Registry:** `io.github.forgeagents-jp/oka-anywhere`
- **Setup guide:** [forgeagentsio.com/oka-guide.html](https://forgeagentsio.com/oka-guide.html)

Three of the four tools use no model at all, so search and verification keep working when the answering engine doesn't. Every plan also includes a printable emergency binder and an offline mode for staff phones — because a power outage shouldn't take the front desk's procedures with it.
